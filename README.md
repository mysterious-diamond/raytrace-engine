# raytrace-engine

<img width="796" height="594" alt="github-raytrace-gif" src="https://github.com/user-attachments/assets/df911080-03f3-44b6-bd4f-314a0c6949a6" />

A simple rendering engine using __raytracing__.

## Controls

1. 'W' or UP key    -> Move camera forward
2. 'S' or DOWN key  -> Move camera backward
3. 'A' or LEFT key  -> Move camera leftward
4. 'D' or RIGHT key -> Move camera rightward

## Libraries

This project was created with a goal to use as
little external libraries as possible to test my skill.

- minifb, to handle window creation and handling!
- rayon, to optimize the engine.
- glam, to optimize 3d vectors.
